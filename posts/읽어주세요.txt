■ 정보글(/info/) — 워드프레스 방에서 홈페이지제작 방으로 이관 (2026-09-16)

주인님 지시: "그럴거면 홈페이지 제작방에다가 넘겨. 그방 따로 이방 따로 하지 말고."
→ 워드프레스 방은 접었다. 정보글은 홈페이지제작 방이 맡는다. (Downloads\CLAUDE.md 색인에도 적어 둠)

■ 왜 워드프레스가 아니라 koreadrain.kr 안인가 (주인님과 합의된 것)
- 주인님 0순위 = "검색했을 때 내 사이트가 노출 → 클릭 → 문의". 애드센스는 아직 없고 후순위.
- 주인님은 사이트를 직접 안 만지신다 → 워드프레스의 유일한 장점(폰에서 직접 수정)이 없다. 호스팅비만 나간다.
- 정보글이 같은 도메인에 쌓여야 koreadrain.kr 자체가 "우수관 전문"으로 올라가고, 글 읽던 사람이 같은 사이트 견적 페이지로 바로 넘어온다.
- 1째방(claude.ai)에서 "별도 도메인"으로 정했던 건 워드프레스라서였다. 깃허브로 오면 그 이유가 없다.
- 애드센스를 나중에 붙이더라도 /info/ 페이지에만 넣는다. 영업 페이지 17장에는 절대 안 넣는다 (경쟁업체 광고 노출 방지).

■ 만들어 둔 것 (src-pack 안, 아직 커밋 안 됨 · build.py 는 안 건드렸다)
- info.py        정보글 빌더. posts/*.txt → dist/info/{slug}.html + dist/info/index.html (목록). 순수 파이썬 (Actions 에 pip 없음).
                 head()·header()·ctabtns()·imgtag()·COPY_JS·NAVER_WCS 는 build.py 것을 그대로 쓴다. CSS 는 EXTRA_CSS 로 덧붙인다.
                 시험 글 1편으로 돌려 h1·표·인용·목록·CTA·BreadcrumbList 정상 확인함 (2026-09-16).
- posts/         글 폴더. 이 파일과 _ 로 시작하는 파일은 빌더가 건너뛴다.

■ build.py 연결 — 2026-09-16 홈페이지제작 30째방에서 완료 (import info / 사진 복사 뒤 urls += info.build). 글 0편이면 /info/ 를 안 만든다.
■ (참고) 원래 안내
  맨 위 import 근처:            import info
  main() 의 사진 복사 직전:      urls += info.build(sys.modules[__name__])
  → /info/ 페이지들이 sitemap.xml 과 IndexNow 에 자동으로 들어간다.
  (info.build 가 b.DIST 를 쓰므로 DIST 정의 뒤에 불러야 한다. main() 안이면 된다)

■ 글에 지킬 것 (koreadrain 원칙 그대로)
- 없는 사실 안 씀. 금액·연수·건수 지어내지 않음 (비용 글은 "정하는 요인 4가지"로, 숫자 없이 — FAQ 와 같은 선).
- "당일 출장·출동·방문" 금지. "사진 보내주시면 당일 견적"은 됨.
- 아파트 얘기 안 씀. 동료 이름 안 씀. 학교·업체·시설 실명 안 씀.
- 다른 현장 공법을 옮겨 쓰지 않는다. 공법 근거는 현장카드 인수인계 3-B절 '기본형'(구글드라이브 현장카드방_인수인계) 과 data.py 의 USUGWAN faq.
- 글 끝 링크는 / (우수관 메인) 하나. 트렌치·보도블록·카스토퍼로는 안 잇는다 (서비스 격리). 지역명은 굳이 안 쓴다.
- 구조는 AEO: 질문형 소제목 + 첫 문단에 즉답 + 표 하나. 1,500자 이상.
- 글마다 뼈대를 바꾼다 (증상→원인→처리 / 비교표 / 순서형 / Q&A).
