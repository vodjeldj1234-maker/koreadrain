[ koreadrain.kr 사이트 소스 ]

■ 폴더 안 파일
   build.py   빌드 스크립트 (실행하는 파일)
   data.py    내용 데이터 — 상호·전화번호·지역·작업 내용이 전부 여기 있음
   style.py   디자인(CSS)
   img/       사진 넣는 폴더 (안에 설명 있음)

■ 실행
   터미널에서 이 폴더로 이동한 뒤:   python3 build.py
   → dist/ 폴더가 생김. 이 dist 폴더를 Netlify 에 폴더째 업로드.
   (Netlify 는 올린 것만 남으므로 반드시 폴더째 올릴 것)

■ 전화번호·상호 바꿀 때  ★가장 자주 쓸 작업
   data.py 맨 위 SITE 딕셔너리에서 phone 과 phone_tel 두 줄만 고치고 다시 빌드.
       "phone":     "010-5033-6117",     ← 화면에 보이는 번호 (하이픈 있음)
       "phone_tel": "01050336117",       ← 누르면 걸리는 번호 (하이픈 없음)
   두 줄을 반드시 같이 고쳐야 합니다. 한 줄만 고치면 표시는 바뀌는데 눌렀을 때 옛 번호로 걸립니다.
   빌드 후 페이지 하나 열어서 하단 통화 버튼을 실제로 눌러 확인하세요.

■ 지역 페이지의 핵심 원칙 (중요)
   지역 페이지에는 다른 지역이 절대 노출되지 않습니다.
   "대전 우수관"으로 들어온 고객에게 수원·화성이 보이면
   "대전 업체가 아니구나" 로 판단해 바로 이탈하기 때문입니다.
   - 지역 페이지 상단 메뉴 = 페이지 내부 이동(증상 진단·작업 범위·출동 지역 등)
   - 지역 페이지 하단 = 그 지역 동네 목록만
   - 로고를 눌러도 전체 지역 목록으로 가지 않음
   검색엔진은 sitemap.xml 과 메인 페이지 링크로 모든 지역 페이지를 수집하므로
   지역끼리 링크를 걸지 않아도 색인에는 문제가 없습니다.
   이 원칙을 깨지 않도록 build.py 의 header() / footer() 는 그대로 두세요.

■ 트렌치 같은 새 작업 추가하는 방법
   1) data.py 를 열고 USUGWAN 딕셔너리를 복사해 TRENCH 로 이름만 바꾼다
   2) slug 를 "trench", name 을 "트렌치" 로 바꾸고 at_root 는 False 로 둔다
      (at_root=False 면 /trench/ 폴더 아래에 만들어짐. 우수관 페이지에는 트렌치가 안 섞임)
   3) symptoms / items / faq 내용을 트렌치 내용으로 바꿔 쓴다
   4) 맨 아래 SERVICES = [USUGWAN] 을 SERVICES = [USUGWAN, TRENCH] 로 바꾼다
   5) python3 build.py 실행 → 트렌치 메인 + 지역 8개 페이지 + 사이트맵이 한 번에 생성됨

■ 지역 추가할 때
   data.py 의 REGIONS 리스트에 항목 하나 추가 → 모든 작업에 그 지역 페이지가 생김
